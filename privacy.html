Monk privacy policy

Last updated: 2026-09-26

Monk is a personal, single-user assistant. It is operated by its developer, javihovito, for their own use only. It has no other users, no accounts, and no website that collects information. This policy describes what Monk does with data from the developer's own Google account.

Google user data Monk accesses

  • Gmail (read-only): sender, subject, date, and message text of messages Monk is asked to search or read, and the sender and subject of unread important messages.
  • Google Calendar (read-only): event titles, times, and locations.

Monk requests only the read-only scopes gmail.readonly and calendar.readonly. It does not send, modify, or delete anything in the account.

How the data is used

Data is used only to provide the assistant's features to its one user: alerting about upcoming meetings, surfacing important email, and answering questions about the calendar and inbox. Monk never uses it for advertising, never sells it, and never uses it to train models.

Where the data goes

  • Stored locally: the Google sign-in token is stored on the developer's own computer in a file that is not shared. Alert lines (a sender and subject, or an event title and time) are kept in local files: an inbox file, an activity log, and daily backups that are deleted after 14 days. Message bodies and other calendar details are not written to Monk's activity log.
  • Sent to service providers, only to deliver the feature: when the developer asks Monk about an email or the calendar, the relevant text is sent to Anthropic (the AI model provider) so the assistant can respond. When Monk speaks an alert aloud, that short alert text is sent to ElevenLabs (text-to-speech). These providers process the text to perform the requested function.
  • Not shared with anyone else. Data is not disclosed to any other third party, except where required by law.

Human access

No person other than the developer reads the data, and the developer only sees their own information.

Retention and deletion

Monk does not keep copies of email or calendar contents beyond the short alert lines described above. The developer can revoke Monk's access at any time at myaccount.google.com/permissions and delete the local token file, which ends all access immediately.

Google API Services User Data Policy

Monk's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
